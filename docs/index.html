Ask the controls.

Put a question to the Singapore Government's IM8 Reform security controls and watch each stage of the retrieval run: pre-filter, two kinds of search, fusion, rerank, a guardrail that decides in code, then a cited answer.

    Pipeline

      How it works

      1. Pre-filter Regex rules refuse prompt injection, other frameworks or laws, and unknown control IDs. No model is involved.
      2. Semantic Embeddings (bge-small) rank all 137 controls by meaning.
      3. BM25 Keyword search ranks the same controls by shared words and IDs.
      4. Fusion Reciprocal rank fusion (k = 60) merges the two lists.
      5. Rerank A cross-encoder re-reads the top 20 candidates against the question and scores each one.
      6. Guardrail A threshold calibrated by cross-validation decides whether to refuse, in code, before any language model is called.
      7. Answer A model answers only from the retrieved controls and cites them as [CONTROL-ID].

      Crosswalk questions, such as "which controls reference NIST SP 800-53 IA-5?", use a structured reference index, because the control text does not contain its references.

      Results

      Read this first. Every benchmark label is pending manual verification: 63 of the 124 questions were generated from catalogue data and 61 were drafted with LLM assistance. The crosswalk gold labels come from the same references the crosswalk index is built from, so those scores show that routing works, not that the references are right.
