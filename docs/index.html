Pipeline

How it works

  1. Pre-filter: regex rules refuse prompt injection, other frameworks or laws, and unknown control IDs. No model involved.
  2. Semantic + BM25: bge-small embeddings and keyword search each rank the 137 controls.
  3. Fusion: reciprocal rank fusion (k=60) merges the two lists.
  4. Rerank: a cross-encoder re-reads the top 20 (raw scores).
  5. Guardrail: a threshold calibrated by cross-validation decides to refuse in code before any LLM call.
  6. Answer: an LLM answers only from the retrieved controls and cites [CONTROL-ID]s.

Crosswalk questions ("which controls reference NIST SP 800-53 IA-5?") use a structured reference index, because the control text does not contain its references.

Results

Read this first. All 124 benchmark questions are unverified: 63 were generated from catalogue data, and 61 were drafted with LLM assistance; gold labels are pending manual verification. The crosswalk gold labels come from the same data as the crosswalk index, so those results measure routing, not independent truth.
